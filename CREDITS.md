# Créditos

- Perfil de arranque: [archiso](https://gitlab.archlinux.org/archlinux/archiso) `releng`, GPL-3.0-or-later, Arch Linux.
- Instalador del disco: [archinstall](https://github.com/archlinux/archinstall), GPL-3.0-or-later.
- Paquetes del sistema: repositorios oficiales `core` y `extra` de Arch Linux.
- Logotipo, fondo de pantalla, splash de Syslinux, esquema PekarchOS Neon, tema de SDDM y perfil de Konsole: obra original de Pekapro, CC0-1.0. El wordmark está dibujado con un alfabeto de píxeles propio; no se incrusta ninguna fuente.
- Iconos Candy: EliverLara, GPL-3.0, commit fijado. Detalle y respaldo Breeze en [THIRD-PARTY.md](THIRD-PARTY.md).
- El script `tools/generate_assets.py` regenera los PNG. Hace falta Pillow solo para eso, no para construir la ISO.
